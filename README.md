# Web Application Penetration Testing (Week 6 - Task 2)

## Overview
This repository contains the deliverables for **Week 6 - Task 2** of the Cyber Security Internship. The project documents a black-box/grey-box web application penetration test conducted using **Burp Suite Community Edition** and **OWASP ZAP** following the **OWASP Web Security Testing Guide (WSTG)**.

## Repository Structure
* `docs/Penetration_Testing_Report.md` - Complete penetration testing report detailing engagement scope, testing phases, risk summary, and strategic remediation.
* `docs/Vulnerabilities_and_PoCs.md` - Detailed technical list of exploited vulnerabilities (SQL Injection, Stored XSS, CSRF, IDOR) with step-by-step Proof-of-Concept (PoC) payloads.

## Tools & Methodology Used
* **Proxy & Exploitation:** Burp Suite Community Edition (Proxy, Repeater, Intruder)
* **Automated Scanning:** OWASP ZAP
* **Framework:** OWASP Web Security Testing Guide (WSTG v4.2) & OWASP Top 10
